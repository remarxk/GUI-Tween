## 执行步骤
1. 任务启动后，必须优先向用户索取 Git 查询起始时间，严格限定格式：`yyyy/MM/dd HH:mm`
2. 未获取合法时间参数时，直接终止全部流程，禁止进行任何后续操作
3. 根据指定时间范围，筛选并读取该时间之后的全部 Git 提交记录
4. 自动对提交记录进行归纳分类，固定分类：新增、修复、优化、兼容
5. 使用标准 Markdown 语法排版，同步输出**完整中英双语**更新日志
6. 最终内容仅在对话内直接返回，禁止生成、导出本地文件

## 约束条件
- 日志文案简洁通俗，删减底层技术细节、代码逻辑等开发向内容
- 强时间校验：无有效起始时间，严禁执行日志生成逻辑
- 全内容双语翻译，不仅限于标题，所有条目均需配套中英对照
- 分类严格贴合提交内容，禁止乱加无关分类项
- 禁止创建与输出任何本地文件
- 已文本框形式输出，输出为原生可复制 Markdown 源码：一级/二级标题使用 #、列表使用 -，无预览格式、无额外修饰符号
