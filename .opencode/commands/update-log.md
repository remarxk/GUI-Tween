## 前提
1. 这是我的世界模组
2. 这是需要发布在Modrinth和CurseForge的更新内容

## 执行步骤
1. 检查项目根目录下是否存在 `updatelog/` 文件夹
   - 若存在，搜索该文件夹下最新的 `updatelog-*.md` 文件，读取文件末尾 HTML 注释中记录的尾次 Git 提交哈希（格式：`<!-- last-git-commit: HASH -->`）
   - 若文件夹不存在或没有任何历史日志文件，向用户索取 Git 查询起始时间（格式：`yyyy/MM/dd HH:mm`），未获取合法时间时直接终止全流程
2. 根据上一步获取的起始点（提交哈希或时间），使用 `git log` 获取该点之后的所有新提交记录
   - 若没有新提交，终止流程并提示用户无需更新
3. 自动对提交记录进行归纳分类，固定分类：新增、修复、优化、兼容
4. 使用标准 Markdown 语法排版，分别生成中文版和英文版更新日志
5. 在 `updatelog/` 文件夹输出两个文件：
   - `updatelog-zh.md` — 中文更新日志
   - `updatelog-en.md` — 英文更新日志
6. 每个文件末尾以 HTML 注释记录本次包含的尾次提交哈希，供下次执行时溯源

## 约束条件
- 日志文案简洁通俗，删减底层技术细节、代码逻辑等开发向内容
- 全内容双语翻译，不仅限于标题，所有条目均需配套中英对照
- 分类严格贴合提交内容，禁止乱加无关分类项
- 新增的更新日志必须基于上次尾次提交之后的提交生成，不得重复包含已有条目
- 禁止创建与输出任何本地文件（`updatelog/` 文件夹内的日志文件除外）
